# Hiba Glam Website

Statische Website für Hiba Glam Friseure in München. Die Seite ist für GitHub Pages vorbereitet und kann ohne Build-Schritt veröffentlicht werden.

## Seiten

- `index.html` - Startseite
- `preise.html` - Preisliste
- `impressum-datenschutz.html` - Impressum und Datenschutz als vorbereiteter Entwurf
- `404.html` - Fehlerseite für GitHub Pages

## Veröffentlichung auf GitHub Pages

1. Nur die Website-Dateien in ein GitHub-Repository committen.
2. In den Repository-Einstellungen GitHub Pages aktivieren.
3. Als Quelle den Branch mit diesen Dateien und den Root-Ordner auswählen.
4. Die Datei `CNAME` enthält bereits `hibaglam.de`.

## Wichtige Hinweise

- Die finalen Impressums- und Datenschutztexte müssen vor Veröffentlichung in `impressum-datenschutz.html` eingesetzt oder geprüft werden.
- Die Preisliste ist mit den öffentlich sichtbaren Salonkee-Preisen vorbefüllt.
- Der Buchungslink ist überall auf `https://salonkee.de/salon/hiba-glam` gesetzt.
